V1.2 - Expanded multi-source ingestion and improved scraping
     - Updated Wellfound parser to extract multiple job positions from a single company card
     - Added support for relative posting times including days, weeks, months, and years
     - Fixed source job ID handling for reliable database deduplication
     - Added Built In pagination to scrape multiple job listing pages instead of only the first 23 postings
     - Cleaned and organized Built In and Wellfound parser code for maintainability
     - Debugged and verified the full ingestion flow from scraping through PostgreSQL storage

V1.3 - Improved data quality and ingestion reliability
     - Added 30-day freshness filter to prevent outdated job postings from being stored
     - Added handling for invalid and expired postings during ingestion
     - Improved ingestion logging with inserted, skipped, invalid, and expired job counts
     - Improved salary parsing and normalized salary values for database storage
     - Fixed Built In CSS selectors and parsing issues
     - Improved job retrieval ordering to display newest postings first using posting date

V1.4 - Added market-based job searching
     - Added Canada, United States, and North America market selection
     - Updated ingestion pipeline to pass the selected market to each scraper
     - Added market-specific Built In feeds for Canada and the United States
     - Added North America support by combining Canadian and United States Built In feeds
     - Added market-specific Wellfound feeds for Canada, United States, and North America
     - Updated FastAPI ingestion endpoint to accept and validate the selected market
     - Updated frontend to allow users to select a search market before finding jobs

V1.5 - Refined Engineerd frontend and job discovery workflow
     - Added "Find New Jobs" workflow to trigger ingestion on demand
     - Added saved jobs functionality using local browser storage
     - Added All Jobs / Saved Jobs filtering
     - Added improved job card interactions with Save and View Job actions
     - Added posting-time labels such as Today, Yesterday, and days ago
     - Improved frontend styling, spacing, cards, filters, buttons, and responsive layout
     - Added visual loading state while new jobs are being ingested
     - Updated database workflow to clear previous search results when switching markets
     - Improved overall frontend organization and usability

V1.6 - Expanded Job Bank ingestion and standardized salary data
     - Added Government of Canada Job Bank as a third job posting source
     - Built a dedicated Job Bank scraper and parser for search results and individual job postings
     - Added concurrent Job Bank detail-page scraping to retrieve external application links
     - Added Job Bank application URL handling using the existing job URL field
     - Added Job Bank source logo for job cards without employer logos
     - Added salary period tracking for hourly, daily, monthly, and annual salaries
     - Updated salary parsing and frontend display to correctly represent different salary periods
     - Fixed Built In salary parsing to distinguish salary values from non-salary text such as location counts
     - Added initial Built In filtering for clearly unrelated engineering roles such as manufacturing and toolmaking
     - Renamed the project to Engineerd to better reflect its focus on engineering, software, data, and technical job discovery
